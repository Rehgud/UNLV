## 0. 한 줄 요약

**상위 계층(L1)은 신뢰도 있게 맞히지만, 하위로 갈수록 클래스가 2,223개까지 늘며 희귀 클래스를 못 맞히는 long-tail이 뚜렷하다.** 학습은 과적합 없이 건강하게 수렴했고, 앙상블이 전 레벨 micro-F1을 약 +0.10 끌어올렸다.

## 1. 실험 세팅

- **과제**: 아미노산 서열 → EC 번호(4단계 계층, 예 `1.2.99.10`) 예측
- **모델**: ECPICK 재현 — 서열 one-hot(21×1000) → CNN(멀티커널) → 레벨별 클래스 확률(sigmoid), threshold 0.5. ESM 등 사전학습 임베딩 없이 서열에서 바로 학습
- **데이터**: 팀 전처리본. train_ec 153,219 / val_ec 5,583 / **test_ec 5,584**
- **평가**: 고정 분할(train_ec 학습 → test_ec 평가). 불완전 EC는 아는 레벨만 평가에 포함
- **하이퍼파라미터(ECPICK 논문 동일)**: 앙상블 10, batch 32, epochs 20, dropout 0.8, relu 384, beta 0.6, pos_weight(불균형 보정) ON
- **레벨별 클래스 수**: L1=7, L2=67, L3=211, L4=2,223

## 3. 지표 이해 (해석의 열쇠)

- **Precision(정밀도)** = 맞은 양성 ÷ 내가 양성이라 예측한 전체 → 예측이 얼마나 믿을 만한가
- **Recall(재현율)** = 맞은 양성 ÷ 실제 양성 전체 → 놓치지 않고 얼마나 잡나
- **F1** = P·R의 조화평균
- **micro**: 모든 클래스 정오답을 합친 뒤 계산 → **흔한 클래스가 지배** ("전체적으로 얼마나 맞나")
- **macro**: 클래스별 F1을 단순평균 → **클래스마다 동등, 희귀 클래스가 크게 반영** ("골고루 맞나")
- 👉 **micro와 macro의 격차 = 쏠림(long-tail)의 크기**

---

## 4. 핵심 해석 5가지

### (1) 계층이 깊어질수록 성능 하락 (L1→L4)
macro-F1: 0.62 → 0.36 → 0.26 → 0.10. 원인은 **클래스 수 폭증(7→67→211→2,223)** + 클래스당 학습 예시 감소 + 미세한 서열 차이 구분 필요. EC 예측의 본질적 구조이며 ECPICK 논문과 같은 경향.

### (2) L4의 macro(0.10) vs micro(0.49) 극단적 격차 = long-tail
- EC 클래스 빈도가 극단적으로 쏠림: 소수의 흔한 효소 vs 수천 개 희귀 효소
- **macro**는 희귀 클래스(대부분 못 맞힘)가 지배 → 0.10, **micro**는 흔한 클래스(잘 맞힘)가 지배 → 0.49
- 즉 **"흔한 효소는 신뢰도 있게, 드문 세부 기능은 대부분 못 맞힌다."** EC 예측의 핵심 난제이자 이번 모델의 한계
- 반대로 L1은 클래스 7개라 쏠림이 약해 macro/micro 격차 작음(0.62 vs 0.66)

### (3) Recall ≫ Precision (특히 L2/L3)
- micro: L2 recall 0.80 / precision 0.32, L3 recall 0.76 / precision 0.29
- 원인: **pos_weight(불균형 보정)** — 희귀 양성 클래스에 큰 가중치를 줘 양성을 적극 예측. 안 하면 threshold 0.5에서 전부 0 예측(F1=0) 함정. 논문 §S4 방식의 의도된 트레이드오프
- 대가로 헛방(FP) 증가 → 정밀도↓. threshold·pos_weight 상한 조정으로 균형 재조정 여지

### (4) 왜 L4 micro(0.49) > L3 micro(0.42)?
- L3: recall 0.76 / precision 0.29 (공격적, 헛방 많음), L4: recall 0.50 / precision 0.47 (균형)
- pos_weight 상한(50배 캡) 때문에 L4 초희귀 클래스는 비례해 부풀지 못함 → 덜 공격적 예측 → 정밀도↑·재현율↓ → P/R 균형으로 F1이 오히려 높음. **성능 우위가 아니라 P/R 균형 차이**

### (5) 학습 건강 = 과적합 없음
- train_loss 0.269→0.139, val_loss 0.201→0.145로 나란히 근접 수렴, val loss 재상승 없음
- **epoch 8~10에서 이미 수렴** → 20 epoch 충분. F1 곡선도 초반 수렴 후 미세 개선

## 5. 앙상블 효과

랜덤 초기화가 다른 10개 모델의 확률을 평균 → 상관없는 실수 상쇄, 분산 감소(배깅 원리). 단일 멤버 대비 **전 레벨 micro-F1 약 +0.10**(예: L1 micro 0.55→0.66). ECPICK이 앙상블 10을 쓰는 이유가 결과로 확인됨.

## 6. 개수로 본 정오답 (근사치, micro-P/R × 라벨 수, 효소당 EC ≈1개 가정)

| Level | 실제 라벨(≈정답) | ✅ 맞게 잡음(TP) | ❌ 놓침(FN) | ⚠️ 헛방(FP) | 모델 총 예측수 |
|---|---|---|---|---|---|
| L1 | 5,584 | ~4,451 | ~1,133 | ~3,414 | ~7,865 |
| L2 | 5,584 | ~4,442 | ~1,142 | ~9,439 | ~13,881 |
| L3 | 5,584 | ~4,240 | ~1,344 | ~10,216 | ~14,456 |
| L4 | 5,575 | ~2,782 | ~2,793 | ~3,090 | ~5,872 |

- **L1~L3**: 놓치는 건 적음(~20~24%)이나 **헛방이 실제 정답의 2~2.5배** → 낮은 정밀도의 개수적 근거(pos_weight 과예측)
- **L4**: 5,575개 중 **~2,782개만 맞고 ~2,793개 놓침(약 50%)** → long-tail이 개수로도 확인

## 8. 학습개수별 성능 — 핵심 결과 ★

**질문**: 학습 예시가 몇 개 이상이면 잘 맞히고, 몇 개 이하면 못 맞히나? (저빈도 클래스 위주로 전처리한 의도의 핵심 검증)

**결론: 클래스당 학습 예시 ~100개가 임계점.** 50개 이하는 사실상 전혀 못 맞히고(recall 0), 101~500개부터 급반등하며, 500개 이상이면 잘 맞힌다.

**L4 (저빈도 집중, test에 등장한 클래스만)**:

| 학습개수 | 클래스 수 | test 샘플 | recall | precision | 맞춘 클래스 비율 |
|---|---|---|---|---|---|
| 1-2 | 18 | 18 | 0.000 | – | 0% |
| 3-5 | 26 | 29 | 0.000 | – | 0% |
| 6-10 | 146 | 172 | 0.000 | – | 0% |
| 11-20 | 254 | 336 | 0.000 | – | 0% |
| 21-50 | 274 | 563 | 0.000 | – | 0% |
| 51-100 | 171 | 532 | 0.032 | 0.309 | 4.7% |
| **101-500** | 345 | 2,981 | **0.649** | 0.536 | **76.5%** |
| 501+ | 40 | 944 | 0.879 | 0.376 | 97.5% |

- **≤50개**: 563개 test 샘플 전부 놓침(recall 0). "맞춘 클래스 비율" 0% = 이 구간 클래스는 **하나도** 못 맞힘
- **51-100개**: 겨우 시작(recall 0.03, 클래스의 4.7%만 뭔가 맞힘) — 여전히 사실상 실패
- **101-500개**: 급반등(recall 0.65, 클래스 76.5%가 맞기 시작) — **여기가 전환점**
- **501+개**: 안정적(recall 0.88, 97.5% 클래스 적중)

**L2·L3도 동일 패턴**: 100개 미만은 recall 0, 101-500 부분적(recall 0.36), 501+ 강함(0.81~0.82). L1은 전 클래스가 501+라 해당 없음.

**의미**: 전처리에서 저빈도 클래스를 다양하게 남겨 "적은 데이터로도 맞히나"를 테스트한 것에 대한 답 = **현재 ECPICK(서열 CNN)은 클래스당 ~100개 이상 있어야 학습되고, 그 미만(특히 50개 이하)은 거의 학습 실패.** 희귀 클래스 대응이 다음 과제(HierEC의 계층 정보 공유, ESM 임베딩, few-shot 기법 등)의 핵심 동기.

## 멘토 요약 (3문장)

서열만으로 ECPICK을 논문 설정 그대로 재현·평가했고, 과적합 없이 잘 수렴했다. 상위 EC(L1)는 macro-F1 0.62로 신뢰도 있게 맞히지만, 하위로 갈수록 클래스가 2,223개까지 늘며 희귀 클래스를 못 맞히는 long-tail이 뚜렷하다(L4 macro 0.10 vs micro 0.49). 클래스별 분석 결과 **학습 예시 ~100개가 임계점**으로, 50개 이하 클래스는 거의 학습 실패(recall 0)한다. 다음은 계층 인식 모델(HierEC)과 ESM feature, few-shot 기법으로 이 저빈도·하위 레벨을 개선하는 것.
