## 0. 한 줄 요약

**상위 계층(L1)은 신뢰도 있게 맞히지만, 하위로 갈수록 클래스가 1,889개까지 늘며 희귀 클래스를 못 맞히는 long-tail이 뚜렷하다.** 학습은 과적합 없이 건강하게 수렴했고, 앙상블이 전 레벨 micro-F1을 약 +0.10 끌어올렸다.

## 1. 실험 세팅

- **과제**: 아미노산 서열 → EC 번호(4단계 계층, 예 `1.2.99.10`) 예측
- **모델**: ECPICK 재현 — 서열 one-hot(21×1000) → CNN(멀티커널) → 레벨별 클래스 확률(sigmoid), threshold 0.5. ESM 등 사전학습 임베딩 없이 서열에서 바로 학습
- **데이터**: 팀 전처리본. train_ec 153,219 / val_ec 5,583 / **test_ec 5,584**
- **평가**: 고정 분할(train_ec 학습 → test_ec 평가). 불완전 EC는 아는 레벨만 평가에 포함
- **하이퍼파라미터(ECPICK 논문 동일)**: 앙상블 10, batch 32, epochs 20, dropout 0.8, relu 384, beta 0.6, pos_weight(불균형 보정) ON
- **레벨별 클래스 수**: L1=7, L2=67, L3=212, L4=1,889 (총 2,175)

## 3. 지표 이해 (해석의 열쇠)

- **Precision(정밀도)** = 맞은 양성 ÷ 내가 양성이라 예측한 전체 → 예측이 얼마나 믿을 만한가
- **Recall(재현율)** = 맞은 양성 ÷ 실제 양성 전체 → 놓치지 않고 얼마나 잡나
- **F1** = P·R의 조화평균
- **micro**: 모든 클래스 정오답을 합친 뒤 계산 → **흔한 클래스가 지배** ("전체적으로 얼마나 맞나")
- **macro**: 클래스별 F1을 단순평균 → **클래스마다 동등, 희귀 클래스가 크게 반영** ("골고루 맞나")
- 👉 **micro와 macro의 격차 = 쏠림(long-tail)의 크기**

---

## 4. 핵심 해석 5가지

### (1) 계층이 깊어질수록 성능 하락 (L1→L4)
macro-F1: 0.66 → 0.40 → 0.31 → 0.14. 원인은 **클래스 수 폭증(7→67→212→1,889)** + 클래스당 학습 예시 감소 + 미세한 서열 차이 구분 필요. EC 예측의 본질적 구조이며 ECPICK 논문과 같은 경향.

### (2) L4의 macro(0.14) vs micro(0.53) 극단적 격차 = long-tail
- EC 클래스 빈도가 극단적으로 쏠림: 소수의 흔한 효소 vs 수천 개 희귀 효소
- **macro**는 희귀 클래스(대부분 못 맞힘)가 지배 → 0.14, **micro**는 흔한 클래스(잘 맞힘)가 지배 → 0.53
- 즉 **"흔한 효소는 신뢰도 있게, 드문 세부 기능은 대부분 못 맞힌다."** EC 예측의 핵심 난제이자 이번 모델의 한계
- 반대로 L1은 클래스 7개라 쏠림이 약해 macro/micro 격차 작음(0.66 vs 0.685)

### (3) Recall ≫ Precision (특히 L2/L3)
- micro: L2 recall 0.81 / precision 0.36, L3 recall 0.77 / precision 0.34
- 원인: **pos_weight(불균형 보정)** — 희귀 양성 클래스에 큰 가중치를 줘 양성을 적극 예측. 안 하면 threshold 0.5에서 전부 0 예측(F1=0) 함정. 논문 §S4 방식의 의도된 트레이드오프
- 대가로 헛방(FP) 증가 → 정밀도↓. threshold·pos_weight 상한 조정으로 균형 재조정 여지

### (4) 왜 L4 micro(0.53) > L3 micro(0.47)?
- L3: recall 0.77 / precision 0.34 (공격적, 헛방 많음), L4: recall 0.55 / precision 0.51 (균형)
- pos_weight 상한(50배 캡) 때문에 L4 초희귀 클래스는 비례해 부풀지 못함 → 덜 공격적 예측 → 정밀도↑·재현율↓ → P/R 균형으로 F1이 오히려 높음. **성능 우위가 아니라 P/R 균형 차이**

### (5) 학습 건강 = 과적합 없음
- train_loss 0.30→0.149, val_loss 0.22→0.157로 나란히 근접 수렴, val loss 재상승 없음 (📊 `ECPICK_learncurve.png`)
- **epoch 8~10에서 이미 수렴** → 20 epoch 충분. F1 곡선도 초반 수렴 후 미세 개선

## 5. 앙상블 효과

랜덤 초기화가 다른 10개 모델의 확률을 평균 → 상관없는 실수 상쇄, 분산 감소(배깅 원리). 단일 멤버 대비 **전 레벨 micro-F1 약 +0.10**(예: L1 micro 0.58→0.685). ECPICK이 앙상블 10을 쓰는 이유가 결과로 확인됨.

## 6. 개수로 본 정오답 (근사치, micro-P/R × 라벨 수 5,584, 효소당 EC ≈1개 가정)

| Level | 실제 라벨(≈정답) | ✅ 맞게 잡음(TP) | ❌ 놓침(FN) | ⚠️ 헛방(FP) | 모델 총 예측수 |
|---|---|---|---|---|---|
| L1 | 5,584 | ~4,537 | ~1,047 | ~3,127 | ~7,664 |
| L2 | 5,584 | ~4,526 | ~1,058 | ~7,963 | ~12,489 |
| L3 | 5,584 | ~4,320 | ~1,264 | ~8,375 | ~12,695 |
| L4 | 5,584 | ~3,076 | ~2,508 | ~2,965 | ~6,041 |

- **L1~L3**: 놓치는 건 적음(~19~23%)이나 **헛방이 실제 정답의 1.6~2.5배** → 낮은 정밀도의 개수적 근거(pos_weight 과예측)
- **L4**: 5,584개 중 **~3,076개만 맞고 ~2,508개 놓침(약 45%)** → long-tail이 개수로도 확인

## 7. 학습개수별 성능 (빈도분석) — ★ 핵심 결과

**질문**: 학습 예시가 몇 개 이상이면 잘 맞히고, 몇 개 이하면 못 맞히나? (저빈도 클래스 위주로 전처리한 의도의 핵심 검증) 📊 `ECPICK_frequency.png`

**결론: 클래스당 학습 예시 ~100개가 임계점.** 50개 이하는 전혀 못 맞히고(recall=0), 101~500개부터 급반등하며, 500개 이상이면 잘 맞힌다. (수정본 `freq_summary__...__fixed.csv` 기준)

**L4 (저빈도 집중, test에 등장한 클래스 기준):**

| 학습개수 | 클래스 수 | test 샘플 | recall | precision | 맞춘 클래스 비율 |
|---|---|---|---|---|---|
| 1-2 | 18 | 18 | 0.000 | – | 0% |
| 3-5 | 26 | 29 | 0.000 | – | 0% |
| 6-10 | 146 | 172 | 0.000 | – | 0% |
| 11-20 | 254 | 336 | 0.000 | – | 0% |
| 21-50 | 274 | 563 | 0.000 | – | 0% |
| 51-100 | 171 | 532 | 0.032 | 0.309 | 4.7% |
| **101-500** | 345 | 2,981 | **0.649** | 0.536 | **76.5%** |
| 501+ | 40 | 944 | 0.879 | 0.376 | 97.5% |

- **≤50개**: 1,118개 test 샘플(18+29+172+336+563) 전부 놓침(recall 0) — 이 구간 클래스는 **하나도** 못 맞힘
- **51-100개**: 겨우 시작(recall 0.03, 클래스의 4.7%만) — 여전히 사실상 실패
- **101-500개**: 급반등(recall 0.65, 클래스 76.5% 적중) — **여기가 전환점**
- **501+개**: 안정적(recall 0.88, 97.5% 적중)

**L2·L3도 동일 패턴**: 100개 미만 recall 0, 101-500 부분적(L2 0.357 / L3 0.366), 501+ 강함(L2 0.809 / L3 0.822). L1은 전 클래스가 501+라 해당 없음.

**의미**: 현재 ECPICK(서열 CNN)은 클래스당 ~100개 이상 있어야 학습되고, 그 미만(특히 50개 이하)은 거의 학습 실패. 희귀 클래스 대응이 다음 과제(C-HMCNN의 계층 정보 공유, ESM 임베딩, few-shot 기법)의 핵심 동기.

> **★ C-HMCNN와 직접 비교 (`ECPICK_vs_HierEC_frequency.png`):** 같은 빈도분석을 C-HMCNN(ESM)에 돌린 결과, ESM은 이 임계점을 **~4~5배 낮춘다** — ECPICK이 recall 0인 21~50개 구간에서 C-HMCNN은 이미 0.56, 51~100개면 0.84. 즉 저빈도 병목의 해법이 "ESM 임베딩"임이 데이터로 확인됨. (자세히는 C-HMCNN 문서 4.5절)

## 8. 한계 & 다음 단계

1. **long-tail(희귀 클래스)이 최대 병목** — L4 macro가 정직하게 보여줌
2. **C-HMCNN(ESM 기반)와 비교 완료** — 전 레벨에서 C-HMCNN이 크게 앞섬 (아래 9절 / `ECPICK_vs_HierEC.png`)
3. **평가 스킴 확장** — 교수님 논문이 반복 hold-out(rsho)이면 그쪽으로도 비교
4. **P/R 튜닝** — threshold·pos_weight로 F1 최적화. 레벨별 전체 threshold 스윕(pos_weight ON/OFF 둘 다) 결과와 방법론 캐비어트는 `EC예측_결과보고서_0714.md` §4.3 참고 — 요약: ON은 thr을 0.5→0.65~0.70으로 올리면 L2/L3 micro-F1이 크게 개선(단 test-set 기준이라 val로 재검증 필요), OFF는 어떤 threshold를 잡아도 개선 여지가 사실상 없음

## 9. vs C-HMCNN (ESM-2 3B + 계층 인식 head)

같은 팀 데이터·평가에서, 계층 인식 head(C-HMCNN)를 ESM-2 3B feature 위에 얹은 모델이 **전 레벨에서 크게 앞선다.** 서열 one-hot CNN은 원거리 의존성·진화 정보를 못 잡아 세부 EC(L3/L4)에서 격차가 벌어진다.

| L2 | 0.501 | **0.904** | 0.404 | **0.744** |

## 9.5 vs 논문 ECPICK (원논문 재현 검증) ★

우리 파이프라인은 교수님 랩(Mingon Kang, UNLV)의 **ECPICK 원논문**(Han et al., *Briefings in Bioinformatics* 2024, `bbad401`)을 재현한 것. 논문 보고치와 대조:

**논문은 4자리 EC(L4) micro-averaged F1 하나로 보고** ("최종 예측은 4번째 레벨만 사용"):

| 평가셋 | 예측한 샘플만 | 전체 샘플 |
|---|---|---|
| Swiss-Prot (신규 858) | 0.876 | **0.566** |
| KEGG *B. subtilis* | 0.89 | 0.77 |
| KEGG *E. coli* | 0.90 | 0.85 |
| KEGG *Streptomyces* | 0.83 | 0.55 |

> "예측한 샘플만" = threshold(FDR<0.05) 넘긴 것만 채점(Swiss-Prot 407/858 = 47%). "전체 샘플" = 미예측도 FN 포함.

**우리 재현 ECPICK (EC-Bench 고정분할, test 5,584): L4 micro-F1 = 0.529 (전체 샘플, threshold 0.5 + pos_weight)**

**결론:**
1. **같은 조건(전체 샘플, L4)이면 거의 일치** — 논문 Swiss-Prot 전체 0.566 ↔ 우리 0.529 (차이 0.04). 데이터·임계값이 다른데도 같은 구간 → 아키텍처 충실 재현의 방증. **학습 데이터가 약 130배 적은데도(2천만 vs 15.3만) 대등.**
2. **논문의 0.876은 "확신 있는 47%만" 채점한 값** — 전체를 채점하는 우리 0.529와 직접 비교 불가. 비교 기준점은 논문의 **0.566**.
3. 재현 조건 차이: 학습(2천만 SwissProt+TrEMBL+PDB vs EC-Bench 15.3만), 평가셋(SwissProt신규/KEGG vs EC-Bench test), 임계값(FDR최적화 vs 0.5+pos_weight). 아키텍처(conv k=4/8/16, β=0.6, ensemble 10, dropout 0.8)는 **동일**.
4. **다음:** 논문처럼 threshold를 FDR 기반으로 최적화하면 "예측한 것만" F1을 더 끌어올릴 여지 있음.

## 멘토 요약 (3문장)

서열만으로 ECPICK을 논문 설정 그대로 재현·평가했고(세미콜론 버그 수정본), 과적합 없이 잘 수렴했다. 상위 EC(L1)는 micro-F1 0.685로 신뢰도 있게 맞히지만, 하위로 갈수록 클래스가 1,889개까지 늘며 희귀 클래스를 못 맞히는 long-tail이 뚜렷하다(L4 macro 0.14 vs micro 0.53). 계층 인식 + ESM feature를 쓰는 C-HMCNN이 전 레벨에서 크게 앞서(L1 micro 0.95, L4 0.67), 다음 방향이 "ESM feature + 계층 인식 head + few-shot"임을 데이터로 보여준다.
